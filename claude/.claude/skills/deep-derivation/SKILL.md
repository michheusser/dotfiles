The topic is: $ARGUMENTS

If that is empty, use the topic from the surrounding conversation.

For this turn only, the abstraction-first rule and the scope limit are suspended. The
user has explicitly asked for the complete treatment.

Structure the answer:

1. The governing principle, stated once.
2. Every case it produces, enumerated, with the derivation from the principle to each.
3. Every exception, with the reason it is an exception rather than a case — what property
   of the principle it violates and why the violation exists.
4. Where the principle stops being predictive, and what replaces it there.

Everything else still holds: precise technical language, no colloquial shorthand,
confidence tags on every claim, no next steps.
